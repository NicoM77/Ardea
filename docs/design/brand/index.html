LockupHeron as tall as 1.25 × the font size, gap 0.22 em, heron raised by 0.05 em. Never set the wordmark without the heron in the logo position.
ColoursInk #1D1D1F · White on dark · Accent #0062C4, app icon from #1A78D6 to #0062C4
Clear spaceHalf the heron's height on every side.
Minimum sizeLogo 96 px wide. Below 24 px use the favicon, not the mark.
OpenThe wordmark in the SVG files is live text and needs Inter Tight installed or loaded; it falls back to the system font. It will be converted to outlines.
