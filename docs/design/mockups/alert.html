Puppet Enterprise: code execution through crafted reports

#142 · CVE-2026-115731Published 3 Nov 2026Updated 17 Nov 20264 sources

Exploited in the wildFix available45Raised from level 4 to 5Raised from level 4 on 17 NovOpen

What happened

Anyone holding a CA-signed agent certificate can run code on the Puppet Server by submitting a crafted report. CISA has listed the flaw as actively exploited since 17 November 2026.

Are we affected

Yes, very likely. Platform Ops runs Puppet Enterprise 2025.9.0, inside the affected range.

2025.0.0 · affected2025.12.1 · fixed
Installed: 2025.9.0

What to do

  1. Upgrade to Puppet Enterprise 2025.12.1 and restart Puppet Server.
  2. Check whether the CA autosigns certificate requests, and restrict it.

Technical details

Description, as published by the source

Deserialization of untrusted data in the report-processing code of Puppet, as used by Puppet Server, in the affected releases, allows a client that holds any CA-signed agent certificate to execute arbitrary code on the Puppet Server as its service user by submitting a report containing a crafted rich-data type via PUT request. Where the certificate authority autosigns requests without strong verification, an unauthenticated network attacker can obtain such a certificate.
