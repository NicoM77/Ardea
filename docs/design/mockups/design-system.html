Design system

Planning-phase proposal · light theme only

The interface borrows four things from the natural-hazard bulletin: a humanist sans with heavy numerals, a five-step danger ramp, a ruled and compact density, and the danger ladder. Navigation, tables and form controls are the standard ones. Level is always a numeral and a word; colour only repeats what they say.

The ramp darkens step by step, so the order survives greyscale and colour-blind viewing. Levels 1 to 3 carry a thin ink edge against the white ground. Ramp colours mean level and nothing else: counts, focus rings, selection, errors and data graphics use ink, paper or blue.

Source Sans 3 throughout; Source Code Pro only for identifiers, versions and vectors. Six fixed sizes (13, 15, 17, 20, 24, 30), no fluid scaling; the only size outside the scale is the numeral of the lead tile. Numerals are lining and tabular. Both families ship with the application as WOFF2 files under the SIL Open Font License; nothing is fetched from a font service.

Working states use shape and word, never the danger colours: red always means level, not status. A finding reads "Affected" or "Unaffected"; "Not affected" is reserved for the working state a person sets.

Layout

Shell
Header band 60 px. Ladder column 300 px, 248 px below 1180 px. Work area up to 1440 px wide.
Breakpoints
1180 px: side columns drop below the main column. 760 px: tab bar at the bottom, ladder flat across the top, tables become stacked records.
Rules
3 px ink under a page title, 2 px ink under a table head, 1 px hairline between rows. No cards, no cast shadows, corners at most 2 px.
Targets
Controls 40 px high on desktop, 44 px on touch widths. Focus ring 2 px in link blue, white on the header band.
Motion
State changes only, 150 ms, ease-out. Nothing animates on load; reduced-motion removes the rest.
