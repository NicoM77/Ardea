Step 3: Repository

Where Ardea reads from

Optional, recommended

Connect the GitHub repository of Customer Portal and Ardea keeps its packages up to date by itself. It reads files; it never builds, installs or runs anything.

  1. On GitHub, open Settings → Developer settings → Fine-grained tokens and generate a new token.
  2. Resource owner: your organization. Repository access: Only select repositories.
  3. Repository permissions: Contents: Read-only. Nothing else.
  4. Expiration: 90 days or what your policy allows. Ardea reminds you 14 days before.
Open GitHub’s token page

Stored encrypted. After saving, Ardea shows only its last four characters and its expiry date.
