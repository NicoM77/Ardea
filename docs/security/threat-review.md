# Security pass along the threat table (task 6.1)

Master plan chapter 14, phase 6, task 6.1: every threat of chapter 9.7, with the mitigation in the code and
the test that proves it. Done on 19.11.2026 against `main` at `b617a17`. The independent review by a person
outside development (task 6.2) is still to come and starts from this page.

Test names are given as `Class.Method`. They live under `tests/` (C#) or `web/` (Angular unit tests in
`*.spec.ts`, Playwright in `web/e2e`). Tests marked *new* came with this pass.

## Fixed in this pass

1. **Security headers on error answers.** The exception handler clears the response before writing a 500, which
   removed CSP, `X-Frame-Options` and the rest. The headers are now set on response start by the first
   middleware (`RequestProtection.SecurityHeaders`).
2. **Rate limits** on the five token links of external addresses (`/notify/addresses/*`), on MFA setup, and on
   every endpoint that calls out of the instance or builds a large answer (new policy `ardea-outbound`).
3. **Request size limit** of 1 MiB in Kestrel and as an early `413` problem.
4. **AI providers follow no redirect.** The three SDKs used their own HTTP clients with automatic redirects; a
   compromised or misconfigured provider could have sent the key header or the model call to another host,
   including a metadata address whose answer would end up in an assessment.
5. **CVE Program archive unpacking is bounded**: inner archive 2 GiB, one record 4 MiB, 2 million files, by
   what the data unpacks to. A zip bomb in the archive could otherwise fill the working volume or the memory.
6. **Exception texts no longer reach non-administrators**: source health reason, GitHub access errors, e-mail
   and webhook delivery errors.
7. **Links from source data** in the web app open only when they are `http`/`https`: the advisory of «What to do»,
   the sources of the model's assessment, and the source list of an alert. Angular already neutralised
   `javascript:`, but not `data:` and other schemes.
8. **Tests added** for the cookie flags and sign-out, for headers on every kind of answer, for injected content
   in every channel, for the hourly cap per channel, and for the limits above.
